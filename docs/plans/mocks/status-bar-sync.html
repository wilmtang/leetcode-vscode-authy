Status bar: profile + session sync

The existing LeetCode: SleezyBunny item keeps opening your profile. A second, adjacent item owns session sync: icon-only while healthy, icon plus a short word when it needs you, and a click opens a quick pick with the status and the one action that fixes it. Hover or click the items in the mock.

    Why two items

    The profile click stays a single, predictable destination. Sync gets its own target so a problem is one click from its fix, without opening a webview first.

    Quiet when healthy

    Healthy sync is an icon only, about 22px of bar, and the quick pick opens on details so Enter never restarts a working listener. Text and a background appear only when you need to act, and the icon shape changes too, so state never depends on color alone.

    Implementation notes

    • Both items left-aligned with adjacent priorities so nothing slips between them.
    • Quick pick uses native createQuickPick; items reuse existing commands (restart, force start, status, settings).
    • errorBackground works on the current 1.57 engine; warningBackground needs 1.63+, so on older hosts warnings fall back to icon + text.
    • Each item has its own id, so either can be hidden from the status bar's context menu.
    • Hidden with the profile item when leetcode.enableStatusBar is off, and on its own while sync is turned off.
